A simple Python application created to practice programming fundamentals. The program generates one or multiple Mega Sena lottery games, ensuring that each game contains six unique random numbers between **1** and **60**, sorted in ascending order.

**Note:** The application interface is in **Portuguese (Brazil).**

## Features

- Generate one or multiple Mega Sena games
- Six unique random numbers per game
- Automatic number sorting
- Input validation
- Clean terminal interface
- Simulated drawing effect with timed output
- Option to generate new games or exit the program.

## Run

```bash
python main.py
```

## Concepts

- Functions
- Lists
- Nested loops **(for and while)**
- Conditional statements **(if, elif, else)**
- Exception handling **(try/except)**
- Random number generation **(random)**
- User input validation
- List manipulation **(append, sort, clear)**
- Program flow control.

## Purpose

This project was developed as a programming exercise to improve Python skills, focusing on loops, data structures, input validation, random number generation, and overall program organization.
