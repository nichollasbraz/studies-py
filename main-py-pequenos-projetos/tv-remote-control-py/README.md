A simple command-line TV remote simulation developed in Python to practice classes, methods, loops, conditional statements, and state management.

**Note:** The program interface is in **Portuguese (Brazil)**.

## Features

• Turn the TV on and off\
• Change channels from **1 to 5**\
• Increase and decrease the volume\
• Highlight the current channel\
• Visual volume indicator\
• Terminal screen clearing\
• ASCII-based TV interface\
• Simple command-line interface.

## Run

```bash
python main.py
```
## Concepts Practiced

• Classes and objects\
• Methods and attributes\
• Loops **(while, for)**\
• Conditional statements **(if, elif, else)**\
• User input handling\
• String formatting\
• State management\
• The **range()** function\
• Terminal manipulation **(os.system)**\
• Object-oriented programming fundamentals.

## Purpose

Developed by Nichollas Braz as a programming exercise to reinforce Python fundamentals and object-oriented programming, focusing on classes, methods, loops, conditional logic, state management, and building an interactive terminal application.
